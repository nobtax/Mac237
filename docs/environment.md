
# Technical Environment

## Project
Ransomware Defense and Recovery Planning

## Operating System
Kali Linux (Virtual Machine)

## Programming Language
Python 3

## Tools
- Git and GitHub
- Python virtual environment
- Kali Linux terminal

## Experiment Objective
Evaluate how effectively backup and recovery
methods restore files after simulated ransomware
damage.

## Safety
All experiments use disposable sample files
in an isolated test directory. No real ransomware
will be executed.
